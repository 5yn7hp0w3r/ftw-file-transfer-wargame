# FTW — File Transfer Wargame 🚩

CTF-wargame в духе OverTheWire — целиком про передачу файлов: скачать, раздать, выгрузить,
закодировать. Заходишь по SSH на хост с намеренно урезанным набором инструментов и тащишь файл
тем, что осталось. Внутри — пароль на следующий уровень. **34 уровня** (0–33) в пяти частях +
fileserver = 35 контейнеров.

## Запуск

```bash
cd RU
./gen-flags.sh                 # сгенерировать пароли-флаги (один раз)
docker compose up -d --build   # собрать и поднять
docker compose down            # погасить
```

## Игра

```bash
ssh level0@localhost -p 3220   # стартовый пароль: start-here
cat task.txt                   # задание всегда в ~/task.txt
```

На каждом уровне в домашке три файла: **`task.txt`** (задание), **`hint.txt`**
(подсказка по желанию) и **`info.txt`** (разбор инструмента).

Порт уровня = **3220 + номер**. Полный райтап — в `SOLVES.md`.

| Часть | Уровни | Про что |
|------|--------|---------|
| 1 · Каналы | 0–7 | scp · curl/wget · python · perl/php/ruby · gawk · /dev/tcp · netcat · tar\|nc |
| 2 · Кодирование | 8–14 | base64/nc · base32 · hex · gzip · openssl AES · ncat --ssl · sha256 |
| 3 · Экзотика | 15–19 | uuencode · XOR · split · UDP · socat |
| 4 · Сжатие/кодировки | 20–27 | base85 · z85 · bzip2 · xz · zlib · UTF-16 · basenc×3 · октали |
| 5 · GHOST (хард) | 28–32 | энумерация · скан портов · распознавание кодировки · strings · XOR-брут |
| Финал | 33 | ✓ ты прошёл всё |

В Ghost-части `task.txt` почти пустой — техника и путь не сообщаются, хост энумеришь сам.

## fileserver (машина «атакующего»)
HTTP `:80`/`:1337` · SSH `:22` (источник для SCP, SFTP-chroot) · nc `:4445-4447` · TLS `:4448` ·
UDP `:4449` · socat `:4450` · ghost `:9029`,`:9032`. Наружу порты не проброшены.
Флаги генерятся на каждом запуске (`gen-flags.sh`) и в git не попадают.

## Windows-часть
`certutil`, PowerShell IWR/IRM/WebClient/IEX, `Get-FileHash` в контейнерах не воспроизводятся
(Windows-контейнеры на Linux непрактичны) — разобраны в странице-компаньоне.

## Системные требования

Намеренно лёгкие — одна версия это 35 небольших контейнеров с общим базовым слоем Debian.

- **ОС:** Linux с Docker Engine, либо macOS/Windows с Docker Desktop.
- **Docker:** Engine ≥ 20.10 и Compose v2 (подкоманда `docker compose`).
- **CPU:** любой x86-64 или arm64; хватит 1 ядра, с 2+ первая сборка быстрее.
- **RAM:** ~100 МБ в простое на все 35 контейнеров; **комфортно от 1 ГБ свободных**, 2 ГБ
  желательно на время первой параллельной сборки.
- **Диск:** ~2–3 ГБ под образы одной версии (общий базовый слой экономит место); ~4–5 ГБ если
  собирать и EN, и RU.
- **Сеть:** интернет нужен только на первый `docker compose up --build` (скачать базу Debian и
  apt-пакеты). Дальше работает полностью офлайн.
- **Порты:** занимает host TCP **3220–3253** (по SSH-порту на уровень). Порты fileserver — внутренние.

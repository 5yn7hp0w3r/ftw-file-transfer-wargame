
============================================================
 LEVEL 0  —  SCP поверх SSH
============================================================
На этом хосте НЕТ curl и wget — зато есть ssh-клиент.
На соседней машине `fileserver` у пользователя scpuser
(пароль: scpflag) лежит файл level1.txt (scpuser заперт в SFTP-chroot — виден только этот файл).
В нём — пароль для level1.

ЦЕЛЬ: скопировать этот файл сюда и прочитать.

Подсказка: scp копирует по SSH так же, как cp — по локали:
           scpuser@fileserver:level1.txt  ->  сюда.  ( man scp / sftp )

Переход дальше (на СВОЁМ хосте, новый терминал):
           ssh level1@localhost -p 3221

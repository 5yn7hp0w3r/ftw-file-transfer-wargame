── Распознавание кодировок (GHOST) ───────────────────────
Половина декода — опознать, ЧТО перед тобой. Приметы:

  алфавит A-Za-z0-9+/ с добивкой '='   → base64
  A-Z2-7 с '='                          → base32
  только 0-9a-f, чётная длина           → hex
  '-'/'_' вместо '+'/'/'                → base64url
  высокая энтропия, без структуры       → сжато/зашифровано

Чем допросить блоб:
  file -            угадать тип по magic-байтам
  xxd | head        глянуть первые байты / заголовок
  ent / entropy     случайность (упаковано vs текст)

Угадай, декодни, проверь вывод, повтори.

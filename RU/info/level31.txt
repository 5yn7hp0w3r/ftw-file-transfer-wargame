── strings и carving (GHOST) ─────────────────────────────
Данные часто спрятаны на виду внутри большого бинарного блоба.
`strings` вытаскивает цепочки печатаемых символов, чтобы
просеять мегабайты шума ради нужного куска.

  strings file                 печатаемые цепочки (>=4 по умолч.)
  strings -n 8 file            только длинные
  grep -a PATTERN file         grep как по тексту
  binwalk file                 найти вложенные файлы/архивы

Хлеб анализа прошивок, триажа малвари, форензики и CTF-стего —
флаг редко лежит один.

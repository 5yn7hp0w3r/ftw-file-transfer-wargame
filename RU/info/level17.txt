── split и сборка ────────────────────────────────────────
split режет файл на куски, cat склеивает обратно. Полезно обойти
лимиты на размер, размазать большую выгрузку по запросам или
обмануть наивный DLP, который палит одну крупную передачу.

  split -b 1M   file part.     по размеру -> part.aa, part.ab
  split -n 5    file part.      на 5 частей
  split -d      ...             числовые суффиксы (part.00 ...)
  cat part.*                    сборка (важен порядок имён)

Потом сверь хэш (уровень 14) — неверный порядок или потерянный
кусок тихо портят результат.

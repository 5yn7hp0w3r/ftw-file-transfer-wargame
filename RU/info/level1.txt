── curl и wget ───────────────────────────────────────────
Два вездесущих HTTP-клиента.

curl — одиночные передачи, куча протоколов.
  -o файл   сохранить      -O   оставить имя с сервера
  -s тихо   -L идти по редиректам   -k без проверки TLS
  -x прокси -H заголовок    -d тело POST

wget — заточен под скачивание/зеркалирование.
  -O файл   вывод (заглавная)   -qO-  тихо, в stdout
  -r -np    рекурсивно          -c    докачать

Классическая путаница: у wget флаг вывода -O (заглавная), у
curl -o (строчная). База для скачивания, если они есть на хосте.
